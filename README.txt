Moscure Payment And Email Configuration Guide
=============================================

Use this file as a quick reference for the main settings that usually need to be changed before launch.


1. Razorpay Credentials
-----------------------
Edit this file:

  razorpay-config.php

Change these constants near the top of the file:

  RAZORPAY_KEY_ID
  RAZORPAY_KEY_SECRET
  RAZORPAY_CURRENCY

Example:

  const RAZORPAY_KEY_ID = 'rzp_live_xxxxxxxxxx';
  const RAZORPAY_KEY_SECRET = 'xxxxxxxxxx';
  const RAZORPAY_CURRENCY = 'INR';

Important:
- Use Razorpay test keys only while testing.
- Replace test keys with live keys before taking real payments.
- Keep RAZORPAY_KEY_SECRET private. It must stay in PHP/backend files only.


2. Paid Checkout Admin And Sender Email
---------------------------------------
Edit this file:

  razorpay-config.php

Change these constants near the top of the file:

  MOSCURE_ADMIN_EMAIL
  MOSCURE_FROM_EMAIL
  MOSCURE_FROM_NAME

What they do:

  MOSCURE_ADMIN_EMAIL
  Receives paid order/payment notification emails after Razorpay payment is verified.

  MOSCURE_FROM_EMAIL
  The sender email used for paid order confirmation emails.

  MOSCURE_FROM_NAME
  The sender name shown in the inbox.

Example:

  const MOSCURE_ADMIN_EMAIL = 'orders@moscure.com';
  const MOSCURE_FROM_EMAIL = 'no-reply@moscure.com';
  const MOSCURE_FROM_NAME = 'Moscure Orders';


3. Reserve Order Form Admin And Sender Email
--------------------------------------------
Edit this file:

  send-order.php

Change these constants near the top of the file:

  ADMIN_EMAIL
  FROM_EMAIL
  FROM_NAME

What they do:

  ADMIN_EMAIL
  Receives reserve order form data submitted before/without Razorpay payment.

  FROM_EMAIL
  The sender email used by the reserve order form email.

  FROM_NAME
  The sender name shown in the inbox.

Example:

  const ADMIN_EMAIL = 'orders@moscure.com';
  const FROM_EMAIL = 'no-reply@moscure.com';
  const FROM_NAME = 'Moscure Orders';

Important:
- If you change email settings in razorpay-config.php, also check send-order.php.
- These two files use separate email constants.
- The server must be allowed to send email from the selected FROM email address.
- For better email delivery, configure SPF, DKIM, and DMARC for the sender domain.


4. Important Log Files
----------------------
These files may be created by the order/payment flow:

  payments-log.csv
  orders-log.csv
  razorpay-error.log

What they are for:

  payments-log.csv
  Stores verified paid Razorpay orders.

  orders-log.csv
  Stores reserve order form submissions.

  razorpay-error.log
  Stores Razorpay/payment related errors.

Do not delete these files unless you have already backed them up.


5. CA Certificate File
----------------------
File:

  cacert.pem

This file is used by PHP cURL to connect securely to Razorpay over HTTPS.

Do not edit this file manually.
Replace it only when updating the trusted CA certificate bundle.
